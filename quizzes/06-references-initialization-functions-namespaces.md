## Ссылка как псевдоним

После `int x = 1; int& r = x;` выполняется `r = 5`. Что изменилось?

::: {.quiz-options}
1. `x` осталось равно `1`.
2. `r` стала ссылкой на другой объект.
3. Создалась независимая переменная `r`.
4. `x` стало равно `5`.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Изменилось `x`.** Ссылка обозначает тот же объект; присваивание через неё не перепривязывает ссылку.

</details>

## Передача без копирования

Как обычно передать большой объект только для чтения, без копирования самого объекта?

::: {.quiz-options}
1. `const T&`.
2. `T* const` с разрешённым изменением объекта.
3. `T` по значению.
4. Всегда только через глобальную переменную.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Через `const T&`.** Ссылка не создаёт копию, а `const` запрещает изменение объекта через этот параметр.

[Повторить: Как передавать аргумент?](../lectures/06-references-initialization-functions-namespaces.md#как-передавать-аргумент){target="_blank"}

</details>

## Изменение аргумента

Какая форма параметра позволяет функции изменить обязательный существующий объект `int` вызывающего кода?

::: {.quiz-options}
1. `const int& value`.
2. `const int value`.
3. `int value`.
4. `int& value`.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**`int&`** связывается с исходным объектом и разрешает его изменение. Передача по значению меняет отдельный параметр.

[Повторить: Как передавать аргумент?](../lectures/06-references-initialization-functions-namespaces.md#как-передавать-аргумент){target="_blank"}

## Необязательный объект

В интерфейсе объект может отсутствовать. Какая форма естественно выражает это в теме лекции?

::: {.quiz-options}
1. Указатель, где `nullptr` означает отсутствие.
2. Скрытое предположение, что адрес всегда равен нулю.
3. `int&`, связанная с несуществующим объектом.
4. Ссылка, которую нужно разыменовать для проверки на отсутствие.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Указатель с возможным `nullptr`.** Ссылка на объект предполагает наличие объекта; отдельное отсутствие нужно выражать явно.

[Повторить: Когда отсутствие объекта допустимо](../lectures/06-references-initialization-functions-namespaces.md#когда-отсутствие-объекта-допустимо){target="_blank"}

## Время жизни локального

Почему нельзя возвращать ссылку на обычную локальную переменную функции?

::: {.quiz-options}
1. Ссылка автоматически получает значение `nullptr`.
2. Ссылки вообще нельзя возвращать.
3. Локальный объект прекращает существовать при выходе из функции.
4. Возврат ссылки всегда копирует весь стек.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Получится висячая ссылка.** Использовать её для чтения уничтоженного объекта нельзя; для такого результата подходит возврат значения.

[Повторить: Локальный результат возвращаем по значению](../lectures/06-references-initialization-functions-namespaces.md#локальный-результат-возвращаем-по-значению){target="_blank"}

</details>

## Инициализация и присваивание

Чем отличается инициализация от присваивания?

::: {.quiz-options}
1. Инициализация задаёт начальное состояние создаваемого объекта, присваивание изменяет уже существующий.
2. Инициализация бывает только у указателей.
3. Отличается только пробелами.
4. Присваивание всегда создаёт новый объект.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Это разные этапы жизни объекта.** Например, `int x = 1` и последующее `x = 2` выполняют разные задачи, несмотря на общий символ `=`.

[Повторить: Инициализация и присваивание](../lectures/06-references-initialization-functions-namespaces.md#инициализация-и-присваивание){target="_blank"}

</details>

## Сужение в фигурных скобках

Анализ объявления `int n{3.5};` в C++20: что произойдёт?

::: {.quiz-options}
1. Будет ошибка компиляции из-за сужающего преобразования.
2. Получится `4`.
3. Получится `3`.
4. Получится `0`.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Объявление некорректно.** List-initialization запрещает такое сужение из `double` в `int`; это вопрос об ошибке, не исполняемый пример.

## Перегрузка и результат

Можно ли объявить в одной области две обычные функции с одинаковыми именем и параметрами, различающиеся только типом результата?

::: {.quiz-options}
1. Нет, одного типа результата недостаточно для перегрузки.
2. Да, компилятор всегда выбирает по переменной слева.
3. Да, если одна возвращает `void`.
4. Да, если вызывать их по очереди.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Нет.** Возвращаемый тип сам по себе не различает такие перегрузки; список параметров должен позволять различить функции.

[Повторить: Локальный результат возвращаем по значению](../lectures/06-references-initialization-functions-namespaces.md#локальный-результат-возвращаем-по-значению){target="_blank"}

## Выбор перегрузки

Есть только `f(int)` и `f(double)`. Какую перегрузку выбирает вызов `f(1)`?

::: {.quiz-options}
1. `f(int)`.
2. Обе.
3. `f(double)`.
4. Вызов всегда неоднозначен.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**`f(int)`.** Литерал `1` имеет тип `int`: точное соответствие лучше стандартного преобразования в `double`.

[Повторить: Как выбрать нужную перегрузку](../lectures/06-references-initialization-functions-namespaces.md#как-выбрать-нужную-перегрузку){target="_blank"}

## Пространство имён

Что даёт квалифицированное имя `math::value`?

::: {.quiz-options}
1. Явно указывает, в каком пространстве имён искать `value`.
2. Преобразует `value` в `double`.
3. Делает `value` приватным полем класса.
4. Создаёт копию `value`.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Оно явно выбирает пространство имён.** Это помогает избежать конфликтов одинаковых имён из разных частей программы.

[Повторить: Пространства имён предотвращают конфликты](../lectures/06-references-initialization-functions-namespaces.md#пространства-имён-предотвращают-конфликты){target="_blank"}
