## Общее и различия

Как связаны современные C и C++?

::: {.quiz-options}
1. Это разные языки с большим общим подмножеством.
2. Любая программа на C корректна и в C++.
3. C++ — только библиотека для C.
4. У языков один общий стандарт.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Это разные языки.** C++ вырос из C, но оба языка развиваются независимо; совместимость конкретной программы нужно проверять.

## Типизация

Что означает статическая типизация C++?

::: {.quiz-options}
1. Типы проверяются при трансляции программы.
2. Все переменные обязаны иметь спецификатор `static`.
3. Тип переменной выбирается при каждом присваивании.
4. Все значения имеют один тип.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Типы проверяются при трансляции.** Статическая типизация не связана со спецификатором `static` и не означает, что все значения известны заранее.

[Повторить: Язык C++](../lectures/00-introduction.md#язык-c-1){target="_blank"}

</details>

## Два шага сборки

Проект уже содержит `CMakeLists.txt`. Какая пара команд сначала настраивает, затем собирает его в каталоге `build`?

::: {.quiz-options}
1. `git init`, затем `git commit`.
2. `cmake -B build`, затем `cmake --build build`.
3. `cmake --build build`, затем `cmake -B build` при ещё не настроенном каталоге.
4. `clang-format`, затем `clang-tidy`.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Сначала `cmake -B build`, затем `cmake --build build`.** Первая команда конфигурирует проект, вторая запускает сборку в подготовленном каталоге.

[Повторить: Cmake](../lectures/00-introduction.md#cmake){target="_blank"}

</details>

## Первая программа

В примере Hello, world какой объект используется для вывода в стандартный поток вывода?

::: {.quiz-options}
1. `std::cout`.
2. `std::cin`.
3. `main`.
4. `return`.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**`std::cout`** — стандартный поток вывода. `main` — функция, с которой начинается выполнение обычной программы, а `return` завершает функцию.

## Области применения

Почему C и C++ применяют в системном ПО и вычислительных ядрах?

::: {.quiz-options}
1. Они запрещают доступ к памяти.
2. Они позволяют управлять ресурсами и создавать эффективные программы.
3. Они автоматически делают любой алгоритм оптимальным.
4. Они требуют отдельный компьютер для каждой переменной.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Контроль ресурсов и возможность эффективной реализации.** Производительность всё равно зависит от алгоритмов, структуры данных и реализации программы.
