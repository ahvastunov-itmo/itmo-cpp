## Новый оператор

Можно ли объявить новый оператор `**` для возведения объекта в степень?

::: {.quiz-options}
1. Да, для любого класса.
2. Да, если возвращать `double`.
3. Да, если он `friend`.
4. Нет: можно перегружать только предусмотренные языком операторы.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Новый синтаксический оператор создать нельзя.** Перегрузка задаёт поведение существующего оператора для пользовательских типов.

</details>

## Приоритет

Можно ли перегрузкой `operator+` повысить приоритет `+` над `*`?

::: {.quiz-options}
1. Да, через возвращаемый тип.
2. Нет: приоритет задаётся языком.
3. Да, если оба аргумента одного класса.
4. Да, если сделать его методом.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Приоритет и группировка выражения не меняются.** Перегрузка определяет выполняемую операцию, а не правила разбора выражения.

[Повторить: Перегрузка операторов](../lectures/09-operator-overloading.md#перегрузка-операторов){target="_blank"}

</details>

## Неперегружаемые операторы

Какие операторы нельзя перегружать? Выберите все верные варианты.

::: {.quiz-options}
1. `::`.
2. `.`.
3. `?:`.
4. `+`.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**`::`, `.` и `?:` не перегружаются.** Сложение `+` может быть перегружено для пользовательских типов.

## Левый операнд

У бинарного оператора, реализованного нестатическим методом класса, что играет роль левого операнда?

::: {.quiz-options}
1. Объект, для которого вызывается метод.
2. Только результат функции.
3. Всегда глобальная переменная.
4. Первый явно записанный параметр.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Сам объект метода.** В `a + b` вызову метода соответствует `a.operator+(b)`: второй операнд передаётся параметром.

[Повторить: Оператор | Как член класса | Не как член класса](../lectures/09-operator-overloading.md#оператор-как-член-класса-не-как-член-класса){target="_blank"}

</details>

## Потоковый вывод

Почему `operator<<` для вывода пользовательского типа обычно свободная функция?

::: {.quiz-options}
1. Потому что `<<` нельзя перегружать.
2. Потому что слева стоит поток, а не объект пользовательского класса.
3. Потому что `std::ostream` нельзя передавать по ссылке.
4. Потому что методы не могут возвращать ссылки.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Левый операнд — поток.** Свободная функция может принять `std::ostream&` и объект; возврат ссылки на поток позволяет продолжить цепочку вывода.

[Повторить: CRational](../lectures/09-operator-overloading.md#crational){target="_blank"}

</details>

## friend

Что даёт функции объявление `friend` внутри класса?

::: {.quiz-options}
1. Запрещает вызывать её снаружи.
2. Автоматически делает её виртуальным методом.
3. Автоматически делает её членом класса.
4. Доступ к закрытым и защищённым членам этого класса.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Предоставляет доступ.** Свободная дружественная функция остаётся свободной функцией; дружба не делает её методом.

[Повторить: friend](../lectures/09-operator-overloading.md#friend){target="_blank"}

</details>

## Постфиксный инкремент

Как в сигнатуре отличают постфиксный `operator++` от префиксного?

::: {.quiz-options}
1. Добавляют параметр `bool`.
2. Меняют имя на `operator+++`.
3. Добавляют фиктивный параметр `int`.
4. Используют только тип результата.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Фиктивный `int` обозначает постфиксную форму.** При обычном синтаксисе `x++` язык сам отличает её от `++x`.

[Повторить: CRational](../lectures/09-operator-overloading.md#crational){target="_blank"}

</details>

## Функтор

Какой оператор позволяет вызывать объект синтаксисом `object(args)`?

::: {.quiz-options}
1. `operator()`.
2. `operator->`.
3. `operator[]`.

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**`operator()` делает объект вызываемым.** Такой объект может также хранить состояние между вызовами.

## Указателеподобный интерфейс

Для чего RAII-обёртка указателя обычно перегружает `*` и `->`?

::: {.quiz-options}
1. Чтобы дать привычный доступ к управляемому объекту.
2. Чтобы нулевой указатель разрешалось разыменовывать.
3. Чтобы освободить ресурс при каждом доступе.
4. Чтобы копирование всегда передавало владение.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Для удобного доступа к объекту.** Владение обеспечивает сама обёртка; наличие операторов не отменяет требования действительного объекта при разыменовании.

[Повторить: operator->, operator*](../lectures/09-operator-overloading.md#operator--operator){target="_blank"}

</details>
