## Адрес и значение

`p` указывает на живой объект `int x`. Как получить сам объект `x` через `p`?

::: {.quiz-options}
1. `*p`.
2. `nullptr`.
3. `&p`.
4. `sizeof(p)`.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**`*p` разыменовывает указатель.** `&p` — адрес самого указателя, а не доступ к `x`.

[Повторить: Операторы & и *](../lectures/03-pointers-arrays.md#операторы-и){target="_blank"}

</details>

## Копирование указателя

После копирования `p` в `q` оба указывают на один живой `int`. Что изменится при присваивании `*q = 42`?

::: {.quiz-options}
1. Только независимая копия числа.
2. Только адрес `q`.
3. Общий объект, доступный через оба указателя.
4. Адрес `p`.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Изменится общий объект.** Копирование указателя копирует адрес, а не создаёт копию объекта по этому адресу.

[Повторить: Семантика указателей](../lectures/03-pointers-arrays.md#семантика-указателей){target="_blank"}

</details>

## Константность

Для `const int* p`, указывающего на существующий `int`, что разрешено?

::: {.quiz-options}
1. Присвоить новое значение через `*p`.
2. Увеличить `*p`.
3. Переназначить `p` на другой подходящий объект.
4. Считать, что исходный объект обязательно объявлен `const`.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Можно менять адрес в `p`.** `const` запрещает изменение объекта через этот указатель; исходный объект при этом может быть неконстантным.

</details>

## nullptr

Какой тип имеет литерал `nullptr`?

::: {.quiz-options}
1. `void*`.
2. `bool`.
3. `std::nullptr_t`.
4. `int`.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**`std::nullptr_t`.** Этот специальный тип преобразуется в нулевой указатель подходящего указательного типа и не смешивается с целыми числами при выборе перегрузки.

[Повторить: Нулевой указатель: nullptr, 0 и NULL](../lectures/03-pointers-arrays.md#нулевой-указатель-nullptr-0-и-null){target="_blank"}

</details>

## Висячий указатель

Указатель на локальный объект сохранён после выхода из его блока. Объект уже уничтожен. Что доказывает проверка `p != nullptr`?

::: {.quiz-options}
1. Что его время жизни продлено.
2. Что объект автоматически восстановлен.
3. Что разыменование безопасно.
4. Только то, что значение указателя не нулевое.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Ненулевой указатель не гарантирует живой объект.** Разыменование такого висячего указателя — неопределённое поведение; здесь мы только анализируем ошибку.

[Повторить: Адрес не продлевает жизнь объекта](../lectures/03-pointers-arrays.md#адрес-не-продлевает-жизнь-объекта){target="_blank"}

</details>

## Размер массива

В текущем блоке объявлен встроенный массив `int a[5]`. Чему равен `sizeof(a) / sizeof(a[0])`?

::: {.quiz-options}
1. `4`.
2. `5`.
3. Всегда `20`.
4. Размеру указателя.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Пяти элементам.** В операнде `sizeof` массив не преобразуется в указатель, поэтому учитывается весь массив.

[Повторить: Когда массив остаётся массивом](../lectures/03-pointers-arrays.md#когда-массив-остаётся-массивом){target="_blank"}

</details>

## Параметр-массив

Что означает параметр функции `int values[]`?

::: {.quiz-options}
1. Ссылку на массив любого размера.
2. Массив с сохранённой длиной.
3. Параметр типа `int*`.
4. Массив, который всегда передаётся целиком по значению.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Параметр корректируется до `int*`.** Размер массива в такой параметр не передаётся; его нужно передавать отдельно или использовать другой интерфейс.

[Повторить: sizeof массива и параметра функции](../lectures/03-pointers-arrays.md#sizeof-массива-и-параметра-функции){target="_blank"}

## Указатель за концом

Для массива `int a[3]` какие действия допустимы? Выберите все верные варианты.

::: {.quiz-options}
1. Сформировать указатель `a + 3`.
2. Разыменовать `a + 3`.
3. Разыменовать `a + 2`.
4. Сформировать `a + 4`.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Допустимы `a + 3` и разыменование `a + 2`.** Указатель за последним элементом можно сформировать, но нельзя разыменовывать; дальше границы арифметика тоже недопустима.

[Повторить: Границы арифметики указателей](../lectures/03-pointers-arrays.md#границы-арифметики-указателей){target="_blank"}

</details>

## C-строка

Сколько элементов в массиве `char text[] = "cat"`?

::: {.quiz-options}
1. `4`.
2. `2`.
3. Зависит от размера указателя.
4. `3`.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Четыре:** три буквы и завершающий нулевой символ `\0`. Длина строки без терминатора при этом равна трём.

## Указатель на функцию

Зачем передавать алгоритму указатель на функцию сравнения?

::: {.quiz-options}
1. Чтобы передавать размер через адрес функции.
2. Чтобы менять правило сравнения, сохраняя общий код алгоритма.
3. Чтобы автоматически увеличить массив.
4. Чтобы сравнение происходило при компиляции во всех случаях.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Меняется правило сравнения.** Один алгоритм поиска может искать минимум или максимум, вызывая переданную функцию с подходящим типом.

[Повторить: Функция как параметр алгоритма](../lectures/03-pointers-arrays.md#функция-как-параметр-алгоритма){target="_blank"}

</details>
