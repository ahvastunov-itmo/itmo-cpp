## Выражение и инструкция

Чем отличаются `i++` и `i++;`?

::: {.quiz-options}
1. Второе увеличивает `i` дважды.
2. Первое всегда является циклом.
3. Это два разных способа объявить переменную.
4. Первое — выражение, второе — инструкция-выражение.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Точка с запятой превращает выражение в инструкцию-выражение.** Само выражение `i++` вычисляет значение и изменяет `i`.

## Выбор ветви

В цепочке `if / else if / else` истинны условия первых двух ветвей. Какие ветви выполнятся?

::: {.quiz-options}
1. Обе первые ветви.
2. Только последняя.
3. Только первая.
4. Ни одна: это ошибка компиляции.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Только первая подходящая ветвь.** Остальные условия цепочки после неё уже не проверяются.

</details>

## Связь else и if

Если фигурные скобки опущены, к какому `if` относится `else`?

::: {.quiz-options}
1. К ближайшему предшествующему `if` без своего `else`, допускаемому синтаксисом.
2. К первому `if` в функции.
3. Сразу ко всем вложенным `if`.
4. К `if` с таким же отступом.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**К ближайшему подходящему `if`.** Отступы не меняют синтаксис; фигурные скобки позволяют явно задать структуру ветвления.

## continue в for

В обычном `for (инициализация; условие; шаг)` выполняется `continue`. Что происходит дальше?

::: {.quiz-options}
1. Снова выполняется инициализация.
2. Цикл безусловно завершается.
3. Шаг пропускается, сразу повторяется тело.
4. Выполняется шаг, затем проверяется условие.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Выполняются шаг и следующая проверка условия.** Поэтому `continue` в `for` не пропускает увеличение счётчика, находящееся в шаге цикла.

[Повторить: continue в цикле for](../lectures/02-expressions-control-flow-functions.md#continuecppref-continue-в-цикле-forcppref-for){target="_blank"}

</details>

## Выход из цикла

`break` выполняется во внутреннем цикле двух вложенных циклов. Что он завершает?

::: {.quiz-options}
1. Всю программу.
2. Только текущую итерацию, как `continue`.
3. Только ближайший охватывающий цикл.
4. Оба цикла.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Только внутренний цикл.** После него выполнение продолжается во внешнем; `break` не равен `return`.

[Повторить: Оператор break](../lectures/02-expressions-control-flow-functions.md#оператор-breakcppref-break){target="_blank"}

</details>

## Передача по значению

Функция получает параметр `int value` и присваивает ему `100`. Что происходит с исходной переменной вызывающего кода?

::: {.quiz-options}
1. Она обязательно становится равна `100`.
2. Её тип становится `double`.
3. Она не меняется от присваивания параметру.
4. Она уничтожается.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Исходная переменная не меняется.** Параметр по значению — отдельный объект, и присваивание меняет его.

## Базовый случай рекурсии

Для чего рекурсивной функции нужен достижимый базовый случай?

::: {.quiz-options}
1. Чтобы каждый вызов запускал новый поток.

## Сокрытие имени

Во внутреннем блоке объявлена новая переменная с тем же именем, что снаружи. Какая доступна по этому неквалифицированному имени внутри блока?

::: {.quiz-options}
1. Обе одновременно.
2. Внутренняя.
3. Имя всегда становится ошибкой.
4. Внешняя.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Внутренняя переменная скрывает внешнюю.** Внешняя при этом продолжает существовать и снова доступна после выхода из внутреннего блока.

[Повторить: Сокрытие имён (shadowing)](../lectures/02-expressions-control-flow-functions.md#сокрытие-имён-shadowingcppref-scope){target="_blank"}

</details>

## Возврат из функции

Что делает `return` внутри цикла в функции?

::: {.quiz-options}
1. Завершает текущий вызов функции.
2. Перезапускает функцию.
3. Переходит к следующей итерации.
4. Завершает только цикл.
:::

<details class="quiz-explanation">
<summary>Ответ и объяснение</summary>

**Завершает текущий вызов функции.** Для завершения только цикла используется `break`, для перехода к следующей итерации — `continue`.
