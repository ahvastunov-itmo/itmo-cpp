# Основы программирования на C++

Основной репозиторий конспектов, слайдов и примеров кода курса.

## Структура

```
lectures/00-introduction.md     лекция: и страница сайта, и слайды
articles/01-setup.md            статья: только страница сайта
articles/01-setup-macos.md      её продолжение: гайд под систему
videos/index.md                 видеоматериалы курса
quizzes/index.md               каталог квизов
quizzes/index.md               каталог квизов
quizzes/index.md               каталог квизов
quizzes/01-types-operators.md   интерактивный квиз к лекции
assets/<материал>/              картинки материала
examples/<материал>/            исходники примеров кода
```

Лекции лежат в `lectures/` и собираются в двух видах: как страница конспекта и как Reveal.js-презентация. Статьи лежат в `articles/`, видео — в `videos/`; оба раздела собираются только как страницы сайта.

## Локальный просмотр

1. Установите Quarto и рекомендуемое расширение `Quarto` для VS Code.
2. Откройте эту папку в VS Code.
3. Выполните:

   ```sh
   quarto preview
   ```

Собрать сайт целиком, без запуска сервера:

```sh
quarto render
```

Результат появится в `_site/`, открывать `_site/index.html`.

## Слайды

Собрать все лекции как Reveal.js-презентации:

```sh
quarto render --profile slides --to revealjs
```

Собрать только одну лекцию:

```sh
quarto render lectures/00-introduction.md --profile slides --to revealjs
```

Результат появится в `_site/slides/lectures/`. Статьи в этот профиль не попадают.

## Новая статья

1. Создайте `articles/<номер>-<имя>.md` и укажите в заголовке `title`, `description` и авторов:

   ```yaml
   ---
   title: "Название статьи"
   description: "Одно предложение о чём это"
   author:
     - name: "Имя автора"
       url: https://t.me/nickname
   page-navigation: false
   ---
   ```

2. Картинки положите в `assets/articles/<номер>-<имя>/`, примеры кода — в `examples/articles/<номер>-<имя>/`. Из статьи на них ссылаются через `../assets/...` и `../examples/...`.
3. Добавьте статью в `_quarto.yml` в панель `articles` (раздел `Статьи`) и в список на `index.md`. В панель `lectures` статьи не добавляются: тогда стрелки «предыдущая / следующая» не будут перекидывать читателя с лекции на статью.

## Квизы

Квизы лежат в `quizzes/` и собираются только как страницы сайта. Вопросы, варианты и объяснения хранятся в Markdown; поведение и стили общие: `assets/quizzes/quiz.js` и `quiz.css`. Для работы квиза не нужны сервер, регистрация или внешние библиотеки. Без JavaScript остаются вопросы со сворачиваемыми разборами.

Вопрос оформляется блоком `.quiz-question` с атрибутом `data-answer="2"` для одного верного варианта или `data-answer="1 4"` для нескольких. Внутри — заголовок `##`, условие, нумерованный список в `.quiz-options` и HTML-блок `<details class="quiz-explanation">` с объяснением и ссылкой на лекцию. Номера верных вариантов отсчитываются от единицы; порядок вариантов в списке определяет их номера. Примеры кода подключаются из `examples/` через `include`.

Для каждой лекции есть квиз с тем же именем файла: всего 24 набора по 10 вопросов. Новый квиз нужно добавить в панель `quizzes` в `_quarto.yml`, каталог `quizzes/index.md`, список на главной и блок лекции, видимый только на сайте. В профиль слайдов квизы не входят.

Для проверки интерактивности установите Node.js 26 (либо поддерживаемую версию LTS, указанную в `package.json`) и выполните:

```sh
npm ci
npm test
```

Команда соберёт сайт, проверит наличие квиза для каждой лекции и ссылки на её разделы, затем проверит каждый квиз в DOM-среде: выбор ответов, проверку нескольких вариантов, подсчёт результата, разбор ошибок и повторное прохождение. Зависимости npm нужны только для тестов; обычная сборка сайта по-прежнему выполняется командой `quarto render`.

## Публикация

В настройках репозитория выберите **Settings → Pages → Build and deployment → Source: GitHub Actions**. После этого каждый push в ветку `main` будет пересобирать и публиковать конспекты и презентации.
