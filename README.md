# Основы программирования на C++

Исходники сайта с конспектами курса. Сайт собирается с помощью [Quarto](https://quarto.org/) и автоматически публикуется на GitHub Pages.

## Локальный просмотр

1. Установите Quarto и рекомендуемое расширение `Quarto` для VS Code.
2. Откройте эту папку в VS Code.
3. Выполните в терминале:

   ```sh
   quarto preview
   ```

Quarto соберёт сайт, откроет его в браузере и будет обновлять страницы после сохранения файлов.

## Слайды

Все лекции можно собрать как Reveal.js-презентации из тех же Markdown-файлов:

```sh
quarto render --profile slides --to revealjs
```

Готовые презентации появятся в `_site/slides/`. Вручную добавлять эту папку в Git не нужно.

## Публикация

В настройках репозитория выберите **Settings → Pages → Build and deployment → Source: GitHub Actions**. После этого каждый push в ветку `main` будет пересобирать и публиковать конспекты и презентации.
